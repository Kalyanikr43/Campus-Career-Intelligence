# Campus Career Intelligence – Student Placement Analytics Dashboard

## 📊 Project Overview

Campus Career Intelligence is a data analytics and business intelligence project designed to analyze student placement outcomes and identify the academic, technical, and professional factors associated with employability.

The project analyzes a dataset of 5,000 student records and presents interactive insights through a Power BI dashboard.

## 🎯 Objectives

- Analyze overall student placement performance.
- Identify factors associated with successful placement.
- Compare placement rates across different student categories.
- Analyze the relationship between internships, projects, skills, attendance, CGPA, and backlogs with placement outcomes.
- Analyze salary patterns among placed students.
- Segment students based on placement risk.

## 🛠️ Tools & Technologies

- **Power BI** – Interactive dashboard and data visualization
- **MySQL** – SQL-based data analysis
- **CSV** – Dataset storage and data source
- **DAX** – Calculated fields and dashboard metrics

## 📊 Dashboard Features

The Power BI dashboard provides:

- KPI cards for overall placement performance
- Interactive slicers for filtering student data
- Placement rate comparisons
- Academic performance analysis
- Internship and project analysis
- Technical and soft skill analysis
- Backlog and attendance analysis
- Extracurricular activity analysis
- Salary analysis
- Placement risk segmentation

## 💡 Key Insights

The analysis helps identify how different student characteristics and career-development factors relate to placement outcomes.

The dashboard can be used by placement teams and academic departments to:

- Identify students who may require additional placement support.
- Understand factors associated with higher placement rates.
- Evaluate the role of internships and projects.
- Monitor the impact of academic performance and backlogs.
- Support data-driven placement strategies.
